# Community conduct

Help people use Sherlock and improve the project. Be respectful, specific, and
constructive when discussing code, product choices, or bugs. Welcome people
with different backgrounds and levels of technical experience.

Harassment, discriminatory language, threats, impersonation, doxxing, and posting
someone else's private information are not acceptable. Keep issues and pull
requests relevant; do not use them for unsolicited sales messages.

Maintainers may remove inappropriate content, close disruptive discussions,
and limit participation to protect contributors. Apply those decisions fairly
and explain them when doing so does not reveal private information.

Report conduct concerns privately through an available maintainer contact on
GitHub. If none is available, request a private contact in an issue without
identifying affected people or repeating the harmful content. Vulnerabilities
use the process in [SECURITY.md](SECURITY.md).
