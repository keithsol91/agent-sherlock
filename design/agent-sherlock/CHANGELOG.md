# Changelog

## 1.0.0 - 2026-09-06

Initial design system derived from the owner-approved cartoon homepage.

- Preserved the original youthful-adult cartoon Sherlock, cream/ink/gold/blue visual direction, spacious editorial layout, and free open-source GitHub framing.
- Added exact implementation palette, typography, spacing, component/state guidance, responsive rules, and accessibility criteria.
- Added machine-readable tokens, CSS variables, starter component styles, and bundled upstream Fraunces/Inter fonts with notices.
- Added agent instructions, copyable prompts, asset specifications/status registry, approved homepage copy, documentation patterns, and review checklist.
- Added visual PDF companion and retained the approved full-page PNG unchanged.

The original image's exact font metadata and design values are unavailable; specified values are normalized implementation choices. Standalone character artwork and vector logos are not included in this release.
